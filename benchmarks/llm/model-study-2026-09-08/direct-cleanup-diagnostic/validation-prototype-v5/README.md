# Source validator v5: complete code delimiters

- **Version:** 5.0
- **Date:** 2026-09-08
- **Status:** In Review

The frozen v5 source hash is `552391856a3db623f063706403534d183da9d4e994cd78387e58383442de081b`. It replaces the v4 quote/code regex with a small protected-span scanner. No deletion, reconstruction, alignment, or semantic eligibility rules change. [v4-to-v5.patch](v4-to-v5.patch) records the complete change.

A complete opening backtick run closes only with the same complete, unescaped run. Shorter, longer, and escaped runs stay inside the protected payload; an unmatched span protects to EOF. Quote escaping, contractions, multiline payloads, and paired quote-style handling retain v4 behavior. Escaped openers outside a span still conservatively start protection. This is a conservative source-protection contract, not a Markdown renderer.

All **24 authored test groups pass**, covering delimiter lengths 1, 2, 3, 5, and 12; shorter/longer nested runs; escaped runs and backslash parity; multiline/unterminated payloads; contractions; and valid filler deletion outside protected code.
